# Project provenance and IP boundary

This prototype is a greenfield project created in this repository.

It is implemented from:

- the high-level product requirements written for this project;
- public WebMCP documentation and the public draft specification; and
- original source, interface, copy, and visual design created for this repository.

This repository does not incorporate source code, schemas, assets, prompts, internal documentation, runtime artifacts, or proprietary implementation details from any prior private system. Similar high-level concepts—bounded capabilities, human authorization, exact-state validation, and execution receipts—are independently expressed here for the WebMCP use case.

Any future contribution must preserve this boundary. Reuse from a private system requires a separate, explicit IP review before it may be considered for inclusion.
